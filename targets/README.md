# targets/ — the shared target library

One home for every real-audio target the Playing God programs (MIMIC, ARTISAN,
IMPRESSIONIST-MIMIC, IMPRESSIONIST) benchmark against, plus the material for the
perceptual metric's ears-validation.

- `LIBRARY-DESIGN.md` — why these clips, from the literature. Read this first.
- `manifest.json` — canonical metadata: sources, licences, axes, per-clip rationale. Edit here.
- `MANIFEST.md` — generated human view + pipeline instructions + attribution ledger.
- `windows.json` — proposed/chosen excerpt windows (generated by `analyze`, hand-editable).
- `tools/` — `fetch-raw.sh` (Mac, downloads), `synth-protocol.mjs` (deterministic
  dtmf-modem synth), `make-targets.mjs` (`analyze` / `build` / `verify`).
- `_raw/` — downloaded/recorded source files (gitignore-able; everything is re-fetchable
  via the manifest URLs + md5s).

The two canonical targets (`westminster-chimes.wav`, `SpeechSignalProcessing.wav`) are
bit-identical copies of `../mimic/targets/*` — never convert or re-normalize them; every
historical SSE number depends on those exact bytes. New programs should point at THIS
folder; `mimic/targets/` stays untouched for old configs.

In-domain synthetic/recoverability targets live in `../mimic/lib/targets.js` and are a
deliberately separate thing (see LIBRARY-DESIGN.md §2).
